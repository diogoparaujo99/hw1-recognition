        \item Describe the hyperparameters you experimented with and the effects they had on the train and test metrics.

        \begin{solution}
I read each image's XML annotations into a 20-class binary label vector.
Following the starter, a class receives zero weight if any instance of that
class is marked difficult. Q1 uses PyTorch's
\texttt{BCEWithLogitsLoss(reduction="none")} directly on raw logits, with no
sigmoid beforehand. It computes numerically stable binary cross-entropy for
each image/class pair. I retain the masked average
\[
L=\frac{\sum_{i,c}w_{ic}\ell(z_{ic},y_{ic})}
        {\max(1,\sum_{i,c}w_{ic})}.
\]
The mask excludes difficult labels from both the loss and its gradients.
The built-in and manual expressions agree on representative inputs, including
extreme logits and masked labels; their gradients are finite. Q2 retains its
manual loss.

The supplied CNN maps $64\times64$ inputs to $64\times16\times16$ features,
so the flattened dimension is 16,384. All four runs use Adam, five epochs,
batch size 64, and seed 0. StepLR halves the rate after epoch three.
Augmentation uses horizontal flips and a 64-pixel crop after four-pixel
reflection padding. Evaluation preprocessing and the protected metric
functions are unchanged.
